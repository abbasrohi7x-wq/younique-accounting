# Unique Pro — یونیک

برنامهٔ مدیریت فروشگاه، انبار و حسابداری؛ کاملاً آفلاین، بدون سرور و بدون کلید API.

## ساختار
- `index.html` — کل برنامه (یک فایل)
- `service-worker.js`, `manifest.json` — حالت آفلاین و نصب به‌صورت اپلیکیشن
- `vendor/tesseract/` — موتور OCR محلی (جزئیات در README داخل همان پوشه)
- `logo.svg`, `icon-192.png`, `icon-512.png`

## انتشار روی GitHub Pages
محتویات این پوشه را (نه خود پوشه را) در ریشهٔ مخزن قرار دهید؛ Settings ← Pages ← Deploy from a branch ← main ← /(root).
برنامه باید از آدرس `http(s)` باز شود، نه مستقیم از فایل.

## OCR آفلاین
اولین بار که آنلاین هستید: «تنظیمات دستیار ← OCR آفلاین ← دانلود». پس از آن OCR بدون اینترنت کار می‌کند.
