# Unique Pro — یونیک

برنامهٔ مدیریت فروشگاه، انبار و حسابداری — کاملاً آفلاین (PWA)، بدون سرور اجباری.

## اجرای محلی

```bash
# هر سرور استاتیک
python3 -m http.server 8080
# سپس: http://localhost:8080
```

یا با Node:

```bash
npx serve .
```

> برای OCR و PWA باید از `http`/`https` باز شود، نه `file://`.

## انتشار روی GitHub Pages (رایگان)

1. یک مخزن GitHub بسازید (مثلاً `unique-pro`).
2. محتویات همین پوشه را در **ریشه** مخزن بگذارید (نه داخل زیرپوشه).
3. در GitHub: **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.
4. بعد از یک دقیقه آدرس شبیه این فعال می‌شود:
   `https://<username>.github.io/<repo>/`

### نکات Pages
- Service Worker و مسیرهای نسبی (`src/engine/...`) روی Pages درست کار می‌کنند.
- برای به‌روزرسانی: push جدید روی `main`.
- اگر نام مخزن با یوزرنیم یکی باشد، سایت روی `https://<username>.github.io/` هم در دسترس است.

## موتور استخراج‌شده (آزمایشی)

```js
// فعال‌سازی موتور جدید
localStorage.setItem('yq_use_new_engine', '1');
location.reload();

// خاموش
localStorage.removeItem('yq_use_new_engine');
location.reload();
```

فایل‌ها: `src/engine/core.js`, `src/engine/fin.js`

## میزبانی، ذخیره‌سازی و انتقال داده

- میزبانی برنامه فقط از مسیر **GitHub → Vercel** انجام می‌شود؛ برای اجرای فروشگاه به سرور API یا پایگاه دادهٔ ابری نیاز نیست.
- داده‌های روزمره روی همان دستگاه در IndexedDB ذخیره می‌شوند.
- انتقال بین گوشی و رایانه از طریق بستهٔ کامل رمزگذاری‌شده انجام می‌شود: خروجی رمزدار بگیرید، فایل را با روش امن به دستگاه دوم منتقل کنید، پیش‌نمایش دامنهٔ بازیابی را بررسی و سپس جایگزینی کامل را تأیید کنید.
- بازیابی، داده‌های فعلی دستگاه مقصد را جایگزین می‌کند؛ برای جلوگیری از تداخل شماره فاکتور، در هر زمان فقط یک دستگاه باید ثبت مالی انجام دهد.
- هیچ همگام‌سازی ابری خودکاری فعال نیست و اطلاعات فروشگاه بدون اقدام صریح کاربر به سرویس ثالث ارسال نمی‌شود.
