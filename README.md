# Unique Pro — یونیک

برنامهٔ مدیریت فروشگاه، انبار و حسابداری — آفلاین‌محور (PWA)، بدون نیاز اجباری به سرور یا پایگاه دادهٔ ابری.

## اجرای محلی

```bash
python3 -m http.server 8080
# سپس: http://localhost:8080
```

یا با Node:

```bash
npx serve .
```

> برای PWA، Service Worker و OCR باید برنامه از طریق `http` یا `https` اجرا شود، نه `file://`.

## انتشار رایگان با GitHub Pages

مخزن این پروژه:
`abbasrohi7x-wq/younique-accounting`

1. در GitHub وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
3. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و ذخیره کنید.
4. پس از پایان انتشار، نشانی زیر را بررسی کنید:

   https://abbasrohi7x-wq.github.io/younique-accounting/

این نشانی، URL مورد انتظار پروژه است؛ تا زمانی که پاسخ زندهٔ سایت و بارگذاری منابع بررسی نشده، نباید آن را انتشار موفق تلقی کرد.

### نکات استقرار

- فایل‌های برنامه باید در ریشهٔ مخزن باقی بمانند.
- `manifest.json` و منابع اصلی از مسیرهای نسبی استفاده می‌کنند تا در زیرمسیر مخزن قابل سرو باشند.
- Service Worker باید با scope همان مسیر پروژه ثبت شود؛ پس از هر انتشار، نسخهٔ کش و به‌روزرسانی کلاینت باید بررسی شود.
- GitHub Pages فقط میزبانی استاتیک ارائه می‌کند و جایگزین API یا سرور اختصاصی نیست.
- Vercel در حال حاضر مسیر انتشار هدف این راهنما نیست؛ تنظیمات قبلی آن تا زمان تأیید کامل Pages دست‌نخورده باقی می‌ماند.

## موتور استخراج‌شده (آزمایشی)

برای فعال‌سازی یا غیرفعال‌سازی موتور جدید، از صفحهٔ «سیستم → موتور برنامه» استفاده کنید. تنظیم مستقیم مرورگر:

```js
localStorage.setItem('yq_use_new_engine', '1');
location.reload();

localStorage.removeItem('yq_use_new_engine');
location.reload();
```

فایل‌ها: `src/engine/core.js` و `src/engine/fin.js`.

## اجرای آزمون‌ها

```bash
pip install playwright
python -m playwright install chromium
python3 -m http.server 8765
# در ترمینال جداگانه:
python3 tests/run_tests.py
```

نتیجهٔ آزمون فقط زمانی معتبر است که روی commit مشخص و در محیط قابل تکرار اجرا شده باشد؛ گزارش قدیمی نباید به‌عنوان نتیجهٔ آخرین نسخه معرفی شود.

## میزبانی، ذخیره‌سازی و انتقال داده

- GitHub مخزن کد و GitHub Pages میزبان استاتیک برنامه است.
- داده‌های عملیاتی روی همان دستگاه و در IndexedDB ذخیره می‌شوند.
- انتقال بین گوشی و رایانه از طریق فایل پشتیبان رمزگذاری‌شده و با اقدام صریح کاربر انجام می‌شود.
- پیش از بازیابی، پیش‌نمایش داده‌ها را بررسی کنید؛ بازیابی کامل می‌تواند داده‌های فعلی دستگاه مقصد را جایگزین کند.
- برای جلوگیری از تداخل شماره فاکتور و ثبت‌های هم‌زمان، تا زمان وجود سازوکار همگام‌سازی تراکنشی، یک دستگاه را مرجع ثبت مالی قرار دهید.
- GitHub Pages پایگاه دادهٔ ابری یا همگام‌سازی خودکار بین دستگاه‌ها فراهم نمی‌کند.
