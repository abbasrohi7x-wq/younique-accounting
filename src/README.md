# راهنمای کد منبع

کد منبع پروژه به‌صورت تدریجی از برنامهٔ اصلی استخراج می‌شود. `index.html` همچنان ورودی اجرایی اصلی است؛ جابه‌جایی یا تقسیم آن بدون بررسی وابستگی‌ها مجاز نیست.

## پوشه‌ها

| مسیر | مسئولیت |
|---|---|
| `engine/` | توابع و اجزای هستهٔ دامنه، محاسبات و منطق مالی استخراج‌شده |
| `ui/` | منطق رابط کاربری، دستیار محلی و قابلیت‌های تعاملی |

## قواعد توسعه

1. قبل از افزودن فایل، بررسی کنید آیا مسئولیت آن در ماژول موجود جای مشخصی دارد.
2. ماژول جدید باید مسئولیت محدود، ورودی/خروجی روشن و وابستگی حداقلی داشته باشد.
3. از تعریف دوبارهٔ نویسنده‌های مالی یا مسیرهای ذخیره‌سازی موازی خودداری کنید.
4. هر تغییر در خرید، فروش، موجودی، پرداخت یا حسابداری باید آزمون رگرسیون متناظر داشته باشد.
5. مسیر بارگذاری فایل‌ها در `index.html` و ترتیب اجرای آن‌ها باید با هر تغییر هماهنگ بماند.
6. فایل‌های تولیدشده یا نسخه‌های پشتیبان را در این پوشه قرار ندهید.

برای نقشهٔ کلی پروژه به [README اصلی](../README.md) و برای آزمون‌ها به [راهنمای آزمون](../tests/README.md) مراجعه کنید.
