# راهنمای گفتار فارسی آفلاین

## معماری فعلی در main

- رابط ضبط و بازبینی متن در `src/ui/offline-voice.js` پیاده‌سازی شده است.
- `index.html` این ماژول را بارگذاری می‌کند و دکمهٔ گفتار دستیار را به `window.voiceRecord` متصل می‌کند.
- موتور تشخیص Vosk در مرورگر و روی دستگاه اجرا می‌شود؛ متن نهایی قبل از ارسال به پیش‌نویس به کاربر نشان داده می‌شود.
- `service-worker.js` ماژول را در پوستهٔ برنامه cache می‌کند و فایل‌های `vendor/vosk/` را در cache مستقل `unique-voice-v1` نگه می‌دارد.

## ساخت بستهٔ قابل آزمون

گردش‌کار `.github/workflows/regression-tests.yml` این مراحل را انجام می‌دهد:

1. بررسی نحوی `src/ui/offline-voice.js` با Node.js.
2. اجرای `scripts/build_static.py`.
3. ساخت خروجی موقت در `dist/` و دریافت نسخهٔ مشخص‌شدهٔ کتابخانهٔ Vosk و مدل فارسی `vosk-model-small-fa-0.42`.
4. راه‌اندازی وب‌سرور روی `dist/` و اجرای آزمون مرورگری.

مدل و فایل‌های Vosk در زمان build از منابع بیرونی دریافت می‌شوند و در مخزن Git commit نمی‌شوند. بنابراین اجرای سرور از ریشهٔ مخزن به‌تنهایی مدل را فراهم نمی‌کند. برای آزمون کامل باید build را اجرا و سپس پوشهٔ `dist` را سرو کرد. دریافت وابستگی‌ها در زمان build به اینترنت نیاز دارد؛ پس از آماده‌شدن و cache شدن فایل‌ها، مسیر runtime برای تشخیص طراحی شده که محلی باشد.

## اجرای محلی

پیش‌نیازها: Python 3، Node.js، دسترسی اینترنت برای مرحلهٔ build، و وابستگی‌های Python/Playwright مطابق `tests/README.md`.

از ریشهٔ مخزن:

```bash
python scripts/build_static.py
cd dist
python -m http.server 8765
```

سپس برنامه را از `http://localhost:8765` باز کنید. برای میکروفون روی گوشی باید از HTTPS استفاده شود؛ `localhost` فقط برای آزمون محلی همان دستگاه است.

## محدودیت‌های اعتبارسنجی

- موفقیت build یا آزمون Chromium، کیفیت تشخیص گفتار فارسی در گوشی واقعی را تضمین نمی‌کند.
- مجوز میکروفون، محدودیت‌های حافظه، توقف/شروع ضبط، کارکرد در پس‌زمینه و اجرای واقعی پس از قطع اینترنت باید روی Android آزمایش شوند.
- متن تشخیص‌یافته باید پیش از اعمال به فرمان یا پیش‌نویس بازبینی شود؛ عملیات مالی نباید صرفاً با تشخیص صوتی بدون تأیید کاربر ثبت شود.
- اگر مدل یا کتابخانه آماده نباشد، باید وضعیت خطا به کاربر نمایش داده شود؛ نبود مدل در خروجی استاتیک را نباید با «خرابی میکروفون» اشتباه گرفت.
