# راهنمای نگهداری مخزن GitHub

این سند قواعد ساده و پایدار نگهداری مخزن Unique Pro را تعریف می‌کند.

## هویت و نام‌گذاری

- نام محصول در رابط و مستندات: **Unique Pro**.
- نام نسخهٔ کاری: **Unique Pro 1.0**.
- زبان مستندات کاربر: فارسی؛ نام فایل‌ها و شناسه‌های فنی: انگلیسی و کوتاه.
- نام فعلی مخزن `younique-accounting` تا زمان بررسی اثر تغییر URL روی GitHub Pages حفظ می‌شود.
- از ساخت مخزن یا شاخهٔ موازی برای نسخهٔ جدید خودداری کنید؛ توسعه روی `main` و با commitهای کوچک انجام شود.

## مسئولیت فایل‌های سطح ریشه

| فایل/پوشه | مسئولیت |
|---|---|
| `README.md` | معرفی، اجرا، انتشار و لینک مستندات |
| `PROJECT_STATUS.md` | فقط وضعیت جاری، ریسک‌ها و شواهد آخرین CI |
| `CHANGES_FA.md` | تاریخچهٔ تغییرات؛ نه گزارش وضعیت جاری |
| `CONTRIBUTING.md` | قواعد تغییر و بازبینی |
| `.gitignore` | فایل‌های موقت و محیط توسعه |
| `.github/workflows/` | CI و کنترل کیفیت |
| `docs/` | تصمیم‌های مهندسی و گزارش‌های فنی |
| `tests/` | آزمون‌های قابل تکرار |
| `vendor/` | وابستگی‌های محلی شخص ثالث همراه مجوز و integrity |

## قواعد تغییرات

1. قبل از ویرایش، شاخه و SHA فعلی را بررسی کنید.
2. از commitهای کوچک با پیام روشن و پیشوندهای `fix:`, `docs:`, `test:`, `refactor:`, `chore:` استفاده کنید.
3. فایل اجرایی یا دادهٔ vendor را فقط با دلیل فنی، بررسی وابستگی و آزمون تغییر دهید.
4. فایل تکراری را فقط پس از جست‌وجوی ارجاع‌ها، مسیرهای Service Worker، manifest و آزمون‌ها حذف کنید.
5. نسخهٔ محصول را در چند فایل مستقل و ناسازگار تکرار نکنید؛ گزارش جاری باید منبع حقیقت وضعیت باشد.
6. ادعای موفقیت فقط با لینک اجرای Actions و SHA همان commit ثبت شود.
7. هیچ دادهٔ واقعی مشتری، رمز، token، کلید API یا backup عملیاتی commit نشود.
8. تغییر نام مخزن، حذف branch یا archive/delete repository فقط پس از بررسی URLها، Pages، Actions، وابستگی‌ها و نیاز مالک انجام شود.

## چک‌لیست قبل از پذیرش تغییر

- [ ] فایل‌ها و مسیرهای مورد استفاده شناسایی شدند.
- [ ] مسیرهای نسبی GitHub Pages و Service Worker بررسی شدند.
- [ ] آزمون‌های مرتبط اجرا شدند.
- [ ] نتیجهٔ CI به commit درست متصل است.
- [ ] README و گزارش وضعیت با نتیجهٔ واقعی هماهنگ‌اند.
- [ ] تاریخچهٔ تغییرات فقط شامل اطلاعات تاریخی است.
