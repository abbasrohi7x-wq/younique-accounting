# همگام‌سازی چند دستگاه با Supabase Free

## ایده
- برنامه همچنان **اولویت با داده محلی** دارد.
- ابر فقط **اسنپ‌شات** کامل فروشگاه را نگه می‌دارد.
- ادغام با همان `syncMerge` فایل‌محور انجام می‌شود.

## راه‌اندازی (۵ دقیقه)

1. در [supabase.com](https://supabase.com) پروژه رایگان بسازید.
2. **SQL Editor** → اسکریپت `supabase/schema.sql` را اجرا کنید.
3. از **Settings → API**:
   - Project URL
   - `anon` `public` key
4. در برنامه: **سیستم → همگام‌سازی** → بخش Supabase را پر کنید.
5. «ساخت فضای کاری جدید» بزنید (یک `workspace_id` و `access_key` می‌سازد).
6. همان مقادیر را در دستگاه دوم وارد کنید.
7. روی یک دستگاه **ارسال به ابر**، روی دیگری **دریافت از ابر**.

## نکات رایگان
- محدودیت حجم و ترافیک طرح Free را رعایت کنید (اسنپ‌شات خیلی بزرگ را فشرده نکنید مگر لازم شود).
- `workspace_id` را مثل رمز نگه دارید (حدس‌زدنش سخت است).
- `access_key` را فقط بین دستگاه‌های خودتان به اشتراک بگذارید.
- برای امنیت بالاتر بعداً می‌توان Auth ایمیل اضافه کرد.

## عیب‌یابی
- خطای CORS: از دامنه HTTPS (Vercel) استفاده کنید نه `file://`.
- RLS / permission: مطمئن شوید policyهای `schema.sql` اعمال شده‌اند.
- Conflict: اول دریافت (merge) سپس ارسال.
