# فهرست مستندات Unique Pro

این پوشه محل نگهداری مستندات فنی، تصمیم‌های مهندسی و راهنماهای نگهداری مخزن است.

## راهنماهای نگهداری

- [راهنمای نگهداری مخزن GitHub](GITHUB_REPOSITORY_GUIDE.md) — قواعد نام‌گذاری، تغییر فایل‌ها، commit و کنترل کیفیت.
- [گزارش ممیزی GitHub](GITHUB_AUDIT.md) — سوابق بررسی تنظیمات و ساختار GitHub؛ برای وضعیت زنده، Actions و تنظیمات فعلی را ملاک قرار دهید.

## معماری و پیاده‌سازی

- [استخراج موتور](ENGINE_EXTRACTION.md) — مستندات جداسازی تدریجی اجزای موتور از فایل اصلی.

## نقشهٔ کد

| مسیر | مسئولیت |
|---|---|
| `index.html` | ورودی اصلی برنامه و رابط اجرایی |
| `src/engine/` | منطق هسته و مالی استخراج‌شده |
| `src/ui/` | منطق رابط، دستیار محلی و قابلیت‌های تعاملی |
| `service-worker.js` | کش و رفتار آفلاین PWA |
| `manifest.json` | فراداده و نصب‌پذیری PWA |
| `vendor/` | وابستگی‌های محلی شخص ثالث، فونت‌ها و مجوزها |
| `tests/` | آزمون‌های رگرسیون و ابزارهای اجرای آزمون |
| `.github/workflows/` | گردش‌کارهای خودکار GitHub Actions |

## قواعد سازمان‌دهی

1. فایل اجرایی اصلی و مسیرهای بارگذاری آن بدون ضرورت فنی جابه‌جا نشوند.
2. فایل‌های فنی جدید در نزدیک‌ترین پوشهٔ مسئولیت‌دار قرار بگیرند.
3. مستندات عمومی و فنی در این پوشه و مستندات کاربر در صورت نیاز در `docs/user/` نگهداری شوند.
4. وابستگی‌های ثالث فقط در `vendor/<name>/` و همراه مجوز و اطلاعات یکپارچگی قرار گیرند.
5. خروجی تست، فایل موقت، پشتیبان واقعی و اطلاعات محرمانه وارد Git نشوند.
6. پیش از حذف یا جابه‌جایی هر فایل، ارجاع‌های کد، مسیرهای نسبی، Service Worker و آزمون‌ها بررسی شوند.
